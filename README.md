# Runway / Routes

A mobile-first decision guide for male student-athletes comparing universities that offer both varsity cross country and professional pilot/flight programs.

## What it includes

- 12 researched university profiles with aviation, athletics, cost, climate, campus, fleet, R-ATP, and airline-pathway notes
- Clearly labeled non-official 1600m/3200m planning estimates for scholarship, recruit, and walk-on conversations
- Search and filters by school and athletic division
- Adjustable five-factor scoring model
- Three-school comparison shortlist
- Direct links to university aviation, athletics, cost, and authorization sources

## Local development

```bash
npm ci
npm run dev
```

## Production

```bash
npm run build
npm start
```

The included `render.yaml` configures a Render Blueprint web service. Recruiting marks are estimates only and should always be confirmed with each coach.
